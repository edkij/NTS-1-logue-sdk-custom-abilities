# AmpClean v0.2 — NTS-1 mkI DELAY FX

Чистый стерео-усилитель с отдельной регулируемой сатурацией, занимающий слот DELAY.

## Управление

- TIME / A: GAIN от -6 dB до +36 dB. Шкала линейна в децибелах; 0 dB находится примерно на 14.3% хода ручки.
- DEPTH / B: SATURATION от полностью чистого сигнала до сильной сатурации.

## Что изменилось относительно v0.1

- диапазон усиления изменён с -24…+24 dB на -6…+36 dB;
- сатурация стала намного более выраженной;
- SAT теперь добавляет до примерно +24 dB внутреннего drive перед soft clip и плавно подмешивает обработанный сигнал;
- SAT=0 по-прежнему полностью обходит waveshaper.

Максимальное усиление +36 dB соответствует примерно 63.1x по амплитуде. Поэтому при высоком GAIN чистый режим может намеренно перегружать последующие стадии NTS-1.
