# OctaClean_v0.1_REVERB

Версия эффекта **OctaClean** для секции **REVERB** Korg NTS-1 digital mkI.

DSP и диапазоны параметров сохранены относительно исходной версии; изменён только API/буферный интерфейс нужной категории.

Для официальной пересборки скопируйте файлы проекта в копию соответствующего шаблона `platform/nutekt-digital/dummy-revfx` из logue-sdk и соберите `make`, затем `make install`.
