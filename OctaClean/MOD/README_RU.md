# OctaClean_v0.1_MOD

Версия эффекта **OctaClean** для секции **MOD** Korg NTS-1 digital mkI.

DSP и диапазоны параметров сохранены относительно исходной версии; изменён только API/буферный интерфейс нужной категории.

Для официальной пересборки скопируйте файлы проекта в копию соответствующего шаблона `platform/nutekt-digital/dummy-modfx` из logue-sdk и соберите `make`, затем `make install`.
