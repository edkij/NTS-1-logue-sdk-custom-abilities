# StereoCh v0.2 — NTS-1 mkI REV FX

Более экстремальная версия StereoCh v0.1.

- TIME / первая параметрическая ручка: **DEPTH** — глубина модуляции. Диапазон расширен примерно до 15 мс excursion на максимуме.
- DEPTH / вторая параметрическая ручка: **ENSEMBLE** — от почти простого хоруса до плотного стерео-ансамбля.
- На максимуме ENSEMBLE работают **6 голосов на левый + 6 на правый канал** с разными задержками, скоростями и фазами LFO.
- На высоких значениях ENSEMBLE основной L/R chorus раздвигается до 180° по фазе LFO, а центральные задержки каналов расходятся.
- По мере роста ENSEMBLE wet-поле становится немного громче, а dry немного тише, чтобы крайнее положение ощущалось действительно плотным.
- Rate не вынесен на ручку и автоматически различается между голосами (~0.48–0.97 Hz).

Формат: пользовательский **REVERB FX** для Nu:Tekt NTS-1 digital mkI, API 1.1-0.
